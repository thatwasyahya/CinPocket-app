# CinPocket

Entraînement gratuit à l'examen civique de naturalisation : les 259 questions de la liste officielle en
QCM à quatre propositions, des mises en situation, des examens blancs au format officiel (40 questions,
45 minutes, réussite à 32) et une révision intelligente. Fonctionne sans connexion.

- **Application web** : https://thatwasyahya.github.io/CinPocket-app/
- **Application Android (APK)** : https://thatwasyahya.github.io/CinPocket-app/CinPocket.apk

## Installer sur Android

**Depuis Chrome (le plus simple)** : ouvrir l'application web, puis menu ⋮ → **Ajouter à l'écran
d'accueil** → **Installer**.

**Avec l'APK** :
1. Télécharger `CinPocket.apk` sur le téléphone, l'ouvrir et autoriser l'installation depuis cette source.
2. Si Google Play Protect affiche « application bloquée », toucher le lien **Installer quand même**.
3. Sur un téléphone avec un profil professionnel qui impose Play Protect, utiliser plutôt l'installation
   depuis Chrome.

Les APK officiels sont signés avec le certificat dont l'empreinte SHA-256 est :

```
61:E3:0B:00:43:1D:44:DD:D0:0D:47:4C:82:61:87:9C:FE:A5:18:0F:A9:4E:35:44:F0:BD:E2:B4:21:FA:95:0D
```

Un APK signé avec un autre certificat ne vient pas de l'auteur.

### Vous avez la version 1.x ?
Elle était signée avec une clé qui n'est plus utilisée : la version 2 ne peut pas s'installer par-dessus
(Android affiche « Application non installée »). Pour garder votre progression :
1. Dans l'ancienne application : **Progrès → Exporter ma progression**, et enregistrez le fichier.
2. Désinstallez l'ancienne application.
3. Installez `CinPocket.apk` (version 2).
4. Tout de suite : **Progrès → Importer une sauvegarde**, puis choisissez le fichier.

### Vous utilisiez l'ancienne adresse thatwasyahya.github.io/CinPocket/ ?
Elle ne fonctionne plus. Ouvrez https://thatwasyahya.github.io/CinPocket-app/ dans le même navigateur :
votre progression y est déjà. N'effacez pas les données du navigateur.
